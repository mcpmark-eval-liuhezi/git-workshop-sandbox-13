# Exercise 1: Git Basics

This file covers the core concepts of Git that every participant should know before we start the workshop.

## What you will learn

- How `git init`, `git clone`, and `git status` fit together in a daily workflow.
- The difference between staged, modified, and staged changes in `git diff`.
- Basic commands like `git add`, `git commit`, and `git log` for tracking your own progress during the exercise.

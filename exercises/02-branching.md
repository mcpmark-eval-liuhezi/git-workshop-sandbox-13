# Exercise 2: Branching

This exercise walks through creating, switching to, and merging branches so you can plan your own feature work in the lab.

## What you will learn

- How `git branch`, `git checkout`, and `git merge` work together to keepparallel work isolated.
- Why branching is the foundation of pull requests and code reviews in real projects.
- How to read a branch graph with `git log --graph` to visualize your history during the demo.
